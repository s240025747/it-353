# Student Activities Management System (SAMS)

## Overview
A centralized system for managing all extracurricular activities at the Saudi Electronic University (SEU). The system allows students to browse activities, register, track attendance, and view their activity history.

## Project Includes
- System description and requirements
- Low fidelity prototypes
- Data Flow Diagrams (Context, Level 0, Level 1)
-  Use Case Model + documented use cases
-  UML Activity Diagrams
-  UML Class Diagram
-  Relational database design (tables, PKs, FKs, normalization)
-  Mid progress and final project reports
-  GitHub repositories for all team members

## Purpose
To improve student engagement, simplify activity management, automate attendance tracking, and generate accurate activity transcripts.
